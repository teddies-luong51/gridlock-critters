## 코어 루프 설계 원칙

하이브리드 캐주얼의 코어 루프는 두 레이어로 구성된다:

**레이어 1 — 코어 루프 (30초 사이클)**
- Action → Feedback → Reward 구조
- 즉각적 피드백(비주얼/사운드 이펙트)이 핵심
- 실패도 즉각적이고 명확해야 한다 (좌절 최소화, 재시도 유도)

**레이어 2 — 메타 루프 (5~30분 사이클)**
- 코어 루프 플레이 → 리소스 획득 → 업그레이드/언락 → 더 나은 코어 루프 플레이
- 장기 목표(컬렉션, 스토리, 랭킹)가 플레이어를 며칠~수주 동안 붙잡는다

## GDD 작성 구조

GDD는 다음 섹션을 반드시 포함한다:

```
1. 개요 (게임 이름, 장르, 타겟 유저, 플랫폼, 핵심 판타지)
2. 코어 루프 (Action-Feedback-Reward 흐름도)
3. 게임플레이 메커닉 (입력, 물리, 규칙)
4. 진행 구조 (레벨 수, 난이도 곡선, 언락 순서)
5. 메타 시스템 개요 (통화, 업그레이드, 컬렉션)
6. 수익화 포인트 (광고 노출 위치, IAP 유인)
7. 레퍼런스 게임 (장르 벤치마크 3개)
```

## 코어 루프 검증 체크리스트

- [ ] 30초 안에 한 사이클이 완성되는가?
- [ ] 실패와 성공이 즉각적으로 인지 가능한가?
- [ ] 레벨 1을 5분 내에 클리어할 수 있는가?
- [ ] 코어 메커닉이 튜토리얼 없이 3번 시도 내에 파악 가능한가?
- [ ] 코어 루프가 메타 없이도 20분 이상 재미있는가?

## 레벨 디자인 가이드

**난이도 곡선 패턴 (하이브리드 캐주얼 표준):**
- 레벨 1~5: 튜토리얼 구간, 신규 메커닉 1개씩 도입
- 레벨 6~20: 점진적 난이도 상승
- 매 10레벨마다 보스/스페셜 스테이지 1개
- 레벨당 클리어 시간 목표: 1~3분

**레벨 스펙 필수 항목:**
- 레벨 번호, 배경/테마
- 등장 장애물/적 종류
- 목표 조건 (스코어, 생존 시간, 오브젝트 수집 등)
- 보상 (통화, 아이템)
- 예상 클리어 시간

## 장르별 코어 루프 패턴

**Idle/Clicker 기반:**
탭 → 리소스 생성 → 자동화 업그레이드 → 오프라인 수익

**Runner 기반:**
스와이프/탭 → 장애물 회피 → 코인 수집 → 거리/점수

**Merge 기반:**
드래그 → 합치기 → 새 오브젝트 언락 → 보드 관리

**Puzzle 기반:**
조각 배치/스왑 → 매칭/클리어 → 목표 달성 → 보상

**Tower Defense/Strategy 기반:**
배치 → 방어 → 리소스 관리 → 업그레이드
