## 하이브리드 캐주얼 비주얼 공식

성공한 하이브리드 캐주얼의 비주얼 특성:

| 요소 | 특성 |
|------|------|
| 컬러 | 채도 높은 원색 위주, 명확한 대비, 밝은 배경 |
| 캐릭터 | 귀엽거나 과장된 프로포션 (머리 크기 > 몸), 명확한 실루엣 |
| UI | 심플하고 큰 버튼, 아이콘 위주, 텍스트 최소화 |
| 이펙트 | 과장된 쥬시니스 (팡팡 터지는 파티클, 바운스 애니메이션) |
| 배경 | 심플하거나 블러 처리, 게임플레이 방해 금지 |

## 스타일 가이드 작성 구조

```
1. 핵심 판타지 (한 줄로 비주얼 목표 정의)
2. 컬러 팔레트
   - Primary Color (메인 브랜드 컬러)
   - Secondary Color (보조)
   - Accent Color (CTA 버튼, 보상 하이라이트)
   - Background (밝은 계열)
   - Danger/Error (빨강 계열)
3. 타이포그래피 (폰트 이름, 사이즈 체계)
4. 캐릭터 가이드 (프로포션, 표정 범위, 아웃라인 두께)
5. 환경/배경 가이드 (원근감, 타일 스타일, 조명 방향)
6. UI 컴포넌트 가이드 (버튼, 팝업, 아이콘 스타일)
7. 이펙트 가이드 (파티클 밀도, 컬러, 지속 시간)
```

## 에셋 스펙 표준 (모바일)

| 에셋 유형 | 해상도 | 포맷 | 메모리 예산 |
|---------|------|------|-----------|
| 캐릭터 스프라이트 | 512×512 | PNG (투명) | ~1MB/캐릭터 |
| 배경 | 1080×1920 | JPG (Q85) | ~500KB |
| UI 아이콘 | 128×128 | PNG | ~50KB |
| 파티클 텍스처 | 64×64 | PNG | ~10KB |
| 버튼/UI 패널 | 9-slice 적용 | PNG | ~100KB |

**아틀라스 그룹핑 규칙:**
- UI 요소는 씬별로 아틀라스 묶음 (MainMenu-Atlas, Game-Atlas)
- 캐릭터 스프라이트는 캐릭터별 아틀라스
- 파티클 텍스처는 Effects-Atlas 하나로 통합

## 애니메이션 가이드

**캐릭터 필수 애니메이션 상태:**
```
Idle        (루프, 1~2초)
Run/Move    (루프, 0.5초)
Jump        (단발, 0.3초)
Win         (루프 또는 단발, 1.5초)
Lose/Death  (단발, 0.8초)
Attack      (단발, 0.4초) — 해당 장르만
```

**UI 애니메이션 원칙 (쥬시니스):**
- 버튼 탭: Scale 1.0 → 0.9 → 1.1 → 1.0 (0.15초)
- 보상 팝업 등장: Scale 0 → 1.1 → 1.0 + 파티클 (0.3초)
- 통화 획득: 코인이 UI 아이콘으로 날아가는 트윈 애니메이션
- 모든 전환: 0.2초 이내 (모바일 사용자는 지연에 민감)
