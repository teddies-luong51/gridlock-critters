## 하이브리드 캐주얼 수익화 구조

하이브리드 캐주얼은 광고 + IAP 혼합 모델을 사용한다. 비율은 장르에 따라 다르지만 일반적으로:
- **광고 수익 60~70%** (보상형 > 전면 > 배너)
- **IAP 수익 30~40%** (소액 스타터팩이 전환율 최고)

## 광고 배치 전략

### 광고 유형별 원칙

| 유형 | 노출 타이밍 | 빈도 캡 | UX 영향 |
|------|-----------|--------|--------|
| **보상형 (RV)** | 플레이어 자발적 시청 | 제한 없음 (자발적) | 긍정적 — 반드시 우선 배치 |
| **전면 (Interstitial)** | 레벨 완료/실패 후 | 3분 또는 3레벨당 1회 | 중립 — 과도하면 이탈 유발 |
| **배너** | 메인 메뉴 하단 | 상시 노출 | 부정적 — 인게임 배치 금지 |

### 보상형 광고 배치 포인트

```
[강력 추천]
- 레벨 실패 후: "광고 보고 부활하기" → 재시도율 30~50% 향상
- 소프트 통화 부족 시: "광고 보고 코인 2배 받기"
- 업그레이드 화면: "광고 보고 무료 업그레이드"
- 일일 보상: "광고 보고 보상 2배"

[선택적]
- 레벨 완료 후: "광고 보고 추가 보상"
- 에너지 시스템 있는 경우: "광고 보고 에너지 충전"
```

### 전면 광고 트리거

```
레벨 완료 → [3레벨마다 또는 3분 이상 경과 시] → 전면 광고 → 메인 메뉴
레벨 실패 → [보상형 광고 미시청 경우] → 전면 광고 (50% 확률)
앱 재시작 → [24시간 내 첫 재시작 제외] → 전면 광고
```

## IAP 구성

### 3티어 가격 구조 (표준)

| 티어 | 가격 | 콘텐츠 | 목표 |
|------|------|-------|------|
| **스타터팩** | $0.99~$1.99 | 하드 통화 소량 + 독점 아이템 | 첫 결제 전환 |
| **미드팩** | $4.99~$9.99 | 하드 통화 중량 + 광고 제거 | 재결제 유도 |
| **프리미엄팩** | $19.99~$49.99 | 대량 하드 통화 + VIP 혜택 | 고래 공략 |

### 광고 제거 IAP

- 가격: $2.99~$4.99
- 제거 범위: 전면 + 배너 (보상형은 유지 — 플레이어에게 이득이므로)
- 전환율 목표: DAU의 2~5%

### IAP 판매 순간

```
첫 레벨 실패 후 → 스타터팩 팝업 (단 1회, 이후는 자연스럽게 노출)
하드 통화 0일 때 → "코인 충전" CTA
7일 연속 플레이 → 로열티 팩 한정 할인
이벤트 기간 → 할인 번들
```

## 플랫폼 정책 주의사항

- **어린이 타겟 게임**: COPPA(미국)/GDPR-K(유럽) 준수 필수 — 행동 타겟 광고 금지
- **랜덤박스**: 일부 국가에서 확률 공시 의무 (한국: 확률형 아이템 표시 필수)
- **구독 IAP**: 자동 갱신 구독은 애플/구글 심사 가이드라인 별도 준수
- **광고 노출 연령**: 13세 미만 사용자에게 전면 광고 제한 권고

세부 SDK 연동 코드는 `references/sdk-integration.md` 참조.
